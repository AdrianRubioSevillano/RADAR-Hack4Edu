# Glosario de guaraní para revisión (NUM2)

Decisiones de traducción de "Números para la vida" de Ciclo II. **Nada de esto lo ha revisado un hablante nativo.** Lo redactó una IA; la seguridad es una estimación suya, no un dato.

Seguridad: **alta** (forma estándar conocida), **media** (hay variantes o se duda del uso escolar), **baja** (forma propuesta, comprobar antes de usar con niños).
